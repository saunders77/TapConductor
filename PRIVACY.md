# TapConductor Privacy Policy

Effective date: July 24, 2026

TapConductor is an offline music-performance application. It does not provide accounts, advertising,
analytics, tracking, cloud synchronization, or telemetry, and it does not upload scores or
performances.

## Data processed on the device

TapConductor processes score files selected by the user, tap and keyboard input, optional MIDI
messages and device names, audio-output information, and realtime performance diagnostics. This
processing occurs locally so the app can display and play the score. The information is not sent to
TapConductor contributors or sold or shared with third parties.

On iPadOS and sandboxed macOS builds, the operating-system document picker may copy a selected score
into the app's private container. The app reads that copy and does not modify the original. The copy
can remain until the operating system clears temporary data or the user removes the app and its data.

The bundled demo score and grand-piano samples are installed with the application. TapConductor does
not request microphone, camera, location, contacts, photos, local-network, or Bluetooth permissions.
Class-compliant MIDI devices are accessed through the operating system's MIDI services when the user
selects one.

## Network access and retention

The application contains no application network client and has no server-side data retention.
Platform stores may independently process purchase, download, crash, or diagnostic information under
their own policies. A future release that adds an updater, crash service, or other network feature
must update this policy before that feature ships.

## User choices

Users choose which scores and MIDI devices TapConductor accesses. Closing the app stops active
performance processing. Scores remain under the user's control in their original location; app
container data can be removed using the operating system's app-removal or storage controls.

## Contact

Privacy questions and deletion requests for any future service can be filed through the project's
public support channel: <https://github.com/saunders77/TapConductor/issues>.

This repository copy is the source text for the public privacy-policy URL required by the Apple App
Store and Microsoft Store. Release owners must publish the same text at a stable HTTPS URL and keep
that URL available for the lifetime of the store listing.
